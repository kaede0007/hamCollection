# 🐹 HamCollection (ハムガチャ)

Reactの学習・練習用として開発している、個性豊かなハムスターたちを集める、コレクション＆ガチャアプリです。  
日々の勉強や仕事を頑張るあなたを、ハムスターたちが全64種類の「応援メッセージ」で癒やしてくれます！

## 📝 キャッチコピー
伝説のシークレットハムを狙え！あなただけの図鑑を完成させよう

## 🛠 構成技術
- **Frontend:** React, TypeScript, Vite
- **Styling:** Tailwind CSS (v4)
- **Routing:** React Router DOM

## ✨ 主な機能
- **ガチャ機能:** レアリティに応じた確率でハムスターをランダム獲得！
- **ハムスター図鑑:** 全64体の個性豊かなハムスターの収集状況を確認可能。
- **応援メッセージ機能:** ゲットしたハムスターをクリックすると、それぞれの特色に合わせた温かいメッセージが吹き出しで飛び出します！
